## 3. Ordre de production recommandé

1. **`ORG-03`** — schéma théorique 2TUP, indépendant de tout ; le plus rapide.
2. **`UML-CTX-01`** puis **`UML-UC-01`** — vue d'ensemble, utile pour se repérer ensuite.
3. **`UML-CLS-01`** — le plus long. À faire quand l'attention est fraîche.
4. **`SCH-REL-01`** et **`SCH-MPD-01`** — dérivent directement du précédent.
5. **`UML-ACT-02`**, puis les trois séquences système.
6. **`UML-SEQO-01/02`**, **`UML-COM-01`** — les plus techniques.
7. **`UML-CMP-01`**, **`UML-DEP-01`** — rapides.
8. **`IHM-01` à `IHM-05`** — captures de l'application existante servant de base.
9. Les trois figures bloquées, **dès réception du recueil de l'existant**.

## 4. Règle de mise à jour

Toute modification d'une figure — ajout, suppression, renumérotation — se répercute **d'abord ici**, puis dans les listes des préliminaires. Une figure qui n'apparaît pas dans cet index n'existe pas.
