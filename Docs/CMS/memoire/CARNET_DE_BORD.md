## 7. Régénérer les listes dans Word

| Élément | Chemin |
|---|---|
| Sommaire | Références → Table des matières personnalisée → **1 niveau** |
| Table des matières | Idem → **3 niveaux** |
| Liste des figures | Références → Table des illustrations → Options → **Style : Légende** |
| Liste des tableaux | Idem → **Style : Légende tableau** |

⚠️ Toujours passer par **Options → Style**, jamais par « Étiquette ».
⚠️ Si Word demande « Voulez-vous remplacer cette table des matières ? », répondre **Non** — sinon il écrase le sommaire.

Pour tout mettre à jour d'un coup : **Ctrl + A**, puis **F9**, puis « Mettre à jour toute la table » quatre fois.
